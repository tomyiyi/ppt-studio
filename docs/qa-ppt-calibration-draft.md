# QA 门禁 PPT 校准阈值草案（DRAFT）

> 状态：提案，未生效。阈值最终由用户拍板。本草案不改变 `agnes_qa.py` 的任何 fail 门禁。

## 1. 为什么需要校准

`agnes_qa.py` 的三项硬指标直接取自 agnes 海报规则（`poster_grand_rules.json` hard_targets），从未针对 PPT 媒介校准。实测：

| 样本 | 留白 [0.35,0.60] | 字阶 [8,16] | 间距 ≥0.6 |
|---|---|---|---|
| 管线旧 deck（8 页，v5 时代） | bullets 5/5 fail（0.256–0.290） | 8/8 fail（1.45–3.27） | bullets 4/5 pass |
| v6 手修版（8 页，用户已选方向） | bullets 5/5 fail（0.253–0.275） | 7/7 fail（1.45–2.2） | 2/5 pass |

v6 的实测方法：从 `fw2026_v6.pptx` 的 slide XML 直接提取文本框/图片占位（坐标映射与管线一致：1280×720，字号 pt→px 按 96dpi），生成等效 SVG 后用**门禁原码**（MD5 核对一致）扫描。方法局限见 §4。

核心冲突：**门禁会 fail 掉用户已经选定的 v6 方向**——v6 把第 4/5 页补到 3 条 bullet（信息密度↑），留白纹丝不动（0.26 左右），因为留白几乎完全由 scrim（占画布 68.8%，见 §3）决定。门禁的"减密度"处方瞄准的是图片/scrim 占比，而用户的诉求是 bullet 数量——两个正交维度，门禁用一个数字同时管，必然误伤其中之一。

## 2. 三项指标的逐项诊断

### 留白 negative_space
- 现状：bullets 页 10/10 fail（两个样本 0.253–0.290），cover 0.29–0.30 fail，table/closing 通过。
- 根因：PPT bullets 页的视觉语言（大配图/scrim 占半页以上）天然留白 ~0.26，海报的 0.35 下限对此不适用。

### 字阶 type_scale
- 现状：在 PPT 上恒 fail（实测 1.45–2.2 vs 目标 8–16）。
- 根因：海报的 hero:micro（8–16×）在 PPT 里不存在；PPT 真实的字阶是标题:正文（实测 1.45–2.2×）。此项在 PPT 上的信号价值≈0，门禁自己都注释了媒介错配。

### 间距 spacing_rhythm
- 现状：管线页 4/5 pass；v6 手摆页（38px/52px 行距）大面积 miss。
- 根因：rhythm 档 [8,16,24,32,48,64,96]±3 对手工微调不友好，但方向是对的（v6 用单文本框均匀 26.4px 的两页拿到 0.80）。

## 3. 关键敏感性（方法诚实声明）

v6 的 scrim（渐变罩，58–69% 画布）恰好卡在门禁"≥70% 视为背景排除"线之下，被计入内容。若把 scrim 视为背景排除，bullets 页留白从 ~0.26 翻转为 **~0.95**（文本只占 ~4%）——门禁结论从"fail 低侧"变为"fail 高侧"，**verdict 完全取决于这一刀**。任何阈值方案都必须先回答 scrim 算什么，否则数字没有意义。

## 4. v6 实测方法与局限

1. 输入：`fw2026_v6.pptx`（MD5 `5c5ff20e377ff482ca214f85e45b1b8e`），8 页。
2. 提取：逐页解析 slide XML；每个 `a:p` 发射一个 `<text>`（字号取段内最大，y = 形顶 + 行高累加，行高 = 字号×1.2，与门禁文本高度模型一致）；`p:pic`→`<image>`，无文本形→`<rect>`；门禁的 70% 背景排除由门禁自己执行，本脚本不做取舍。
3. 扫描：门禁原码（与仓库内 `scripts/agnes_qa.py` MD5 一致）。
4. 局限：
   - 按段落（非视觉行）发射 y；v6 bullet 页经渲染图放大核对，段落数 = 视觉行数，一致。
   - 多字号段落取最大（v6 未触发）；缺字号回退 18pt（v6 未触发）。
   - 无填充装饰形按门禁字面规则计入面积（门禁不区分填充）；v6 表格矩形均为实心填充。
   - 字号 pt→px 按 96dpi，与管线 px 体系同单位；跨样本对比有效。
   - 首次运行时 04_bullets 间距曾报 0.50（1/2），随后 3 次复跑 + 直接解析输入均为 0.80（4/5），输入文件含 7 个文本元素无缺失；采用可复现的 0.80，并如实记录这次分歧。

## 5. 阈值提案（选项，用户拍板）

### 选项 A：按页型分档（最小改动，推荐）
- 留白：bullets 页 `[0.20, 0.40]`；cover/table/closing 维持 `[0.35, 0.60]`。
- 字阶：改为标题:正文比，`[1.3, 3.0]`（覆盖实测 1.45–2.2，留余量）。
- 间距：维持 rhythm 档与 ≥0.6（方向正确，手摆页 miss 是真实信号）。
- 代价：门禁需知道页型（cover/bullets/table/closing），小改动。

### 选项 B：统一 PPT 带（改动小，信号弱）
- 留白统一 `[0.22, 0.62]`；字阶同 A；间距容差 ±3→±5。
- 代价：带放得太宽，对真正稀疏/拥挤的页面失去区分度。

### 选项 C：拆分指标（最治本，改动大）
- 留白拆为"背景处理占比"（图/scrim 面积）与"内容密度"（文本面积/内容区）两个指标；scrim 明确计入背景。
- 先回答 §3 的 scrim 问题，再定阈值。此选项需另立方案，不在本次草案内。
