## 第 11 轮（2026-09-30 17:43）：brief_writer.py —— 三段式第 3 段 Agnes 撰写

- **来源**：用户批准接入 research_to_spec 第 3 段
- **改动**：新增 `scripts/brief_writer.py`
  - `build_brief_prompt()`：铁律 prompt——只写有来源支撑的内容，无来源不写；引用格式统一 `[n]`；A/B 级优先；无来源子主题写"暂无可靠来源支撑，略去"

- **验证**：`tests/test_brief_writer.py` 8/8（mock HTTP，不调真实 API）；全量 937 passed + 16 subtests
- **用法**：`python3 scripts/brief_writer.py brief.json -o report.md`（`--dry-run` 只看 prompt）
