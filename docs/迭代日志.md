## 第 13 轮补记（2026-09-30 18:0x）：搜索 API 改用 POST，签名链路打通

**关键发现**：
- 搜索 API `edith.xiaohongshu.com/api/sns/web/v1/search/notes` **仅支持 POST**——GET 返回 404 纯文本，无法区分路径是否存在（浏览器抓包任务确认了 POST 行为）。
- POST + xyw 签名 → HTTP 461（风控拒绝）；POST + 默认 xys 签名 → **HTTP 200**（xhshow 文档称 xyw 用于数据接口，但搜索接口实测要求 xys）。
- HTTP 200 返回 `{"success": false, "msg": "登录已过期"}`——签名链路完全打通，endpoint 有效，**卡在用户 Cookie 的登录态已过期**（sigcli 的 SKILL.md 证实这是小红书常见"灰区"：宽松接口验 Cookie 有效，搜索接口要求更严）。

**改动**：
- `scripts/xhs_sign.py`：`SEARCH_API` 改回 edith/v1（so/v2 是错误线索，已废弃）；新增 `signed_post_headers()`（POST + xys + x-rap-param）；`api_search_notes()` 改用 POST 发 JSON body；`build_search_params()` 返回 int 类型页码。
- `tests/test_xhs_sign.py`：新增 `TestSignedPostHeaders`（断言 xys 前缀/13位时间戳/x-rap-param/Content-Type）；`test_parses_items` 增加 Request.method == POST 断言。

**验证**：
- 全量 **952 passed + 16 subtests**，全绿。
- 真实请求：本轮仅 2 次 POST 探测（1 次 461 + 1 次 200），未触发验证码。

**未闭环（需用户配合）**：
- 搜索 API 返回"登录已过期"——需要用户重新登录小红书小号、提供新的 Cookie，替换 `~/.config/ppt-studio/xiaohongshu.json` 后即可跑通真实搜索。
- 在拿到新 Cookie 前，不要再发真实请求（防风控）。
