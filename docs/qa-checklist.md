# 交付前质检清单

**原则：做完要验证。返回码成功 ≠ 结果正确。**

本项目踩过的坑里，有一半是「脚本跑通了但其实在骗人」。所以这份清单不是走形式，每一项都要读输出、做判断。

---

## 一、图像（每张）

```bash
python3 scripts/analyze_image.py projects/xxx/images/*.png
```

- [ ] 主体锐度 ≥ 80（发光软边可放宽到 ~45）
- [ ] P99 ≥ 40（没有高光说明没画出来）
- [ ] 主体分布最高格 ≥ 25%（每格基线 11%，低于 15% 视为没画出图形）
- [ ] 墨量 ≥ 6%（用 **max(R,G,B) 通道**，不要用亮度）
- [ ] 接缝 = None
- [ ] 主体落位和文字侧不冲突（文字在左 → 主体靠右）

🔴 判彩色笔画必须看 **max(R,G,B) 通道**。靛蓝 `#6E7BFF` 蓝通道 255，但相对亮度权重只有 0.0722，折算灰度约 136。按亮度判会把满饱和靛蓝误判成"太暗"。

## 二、版面（每页）

```bash
/opt/homebrew/bin/python3 scripts/render_svg.py projects/xxx/svg_output qa_render
/opt/homebrew/bin/python3 scripts/qa_layout.py projects/xxx/svg_output qa_render
```

七项，全部 OK 才输出 `ALL CLEAR`：

- [ ] `[字号]` — 所有文本落在 spec_lock 的九档内
- [ ] `[底图]` — 最大 `<image>` 面积 / 画布 ≥ 90%
- [ ] `[重影]` — 同一源图在一页只出现一次
- [ ] `[溢出]` — 文本不超出画布，`text-anchor="end"` 边界是 `[x-w, x]`
- [ ] `[压行]` — 相邻文本行不碰撞
- [ ] `[面板]` — 面板墨量 ≥ 6%
- [ ] `[对比]` — WCAG ≥ 4.5:1（背景取 20 分位、字色取 99.5 分位）

### 字号一致性（单独再核一遍）

`[字号]` 只检查"在不在阶梯上"，不检查"同一角色是不是同一档"。手动核：

| 角色 | 应有档位 | 02 | 03 | 04 | 05 | 06 | 07 |
|---|---|---|---|---|---|---|---|
| statement（页面主句） | 56 | | | | | | |
| headline（大数字） | 44 | | | | | | |
| subtitle（卡片标题） | 24 | | | | | | |
| body（正文） | 16 | | | | | | |

曾经的事故：主句在 02/07 是 56、03 是 72、04/05 是 44 —— 四个尺寸干同一件事，人眼一眼看出"一时大一时小"，但自动化检查全过。

## 二·五、卡片（如果出了卡片）

```bash
python3 scripts/qa_cards.py projects/xxx/cards qa_cards_render
```

- [ ] `[字号]` 落在 `card_spec.md` 的七档内（28/36/44/56/72/96/132）
- [ ] `[安全区]` 文本不越 64px 硬安全边
- [ ] `[溢出]` 不出画布
- [ ] `[压行]` 文本块之间不重叠
- [ ] `[对比]` WCAG ≥ 4.5:1
- [ ] `[底图]` 图片带 ≥ 40% 且墨量 ≥ 2%（防图没加载上）
- [ ] `[留白]` 面板墨量 3%–35%
- [ ] 主句左侧 6px 强调竖线在所有卡片上一致
- [ ] 检查 `[fit]` 输出：被砍掉的副句 / 指标是不是可以接受的取舍

## 二·六、视频与配音（第四出口）

```bash
python3 scripts/qa_video.py projects/xxx/output/xxx_1080p.mp4
```

七项客观质检全部 OK 才输出 `ALL CLEAR`：

- [ ] `[流完整性]` 包含且仅包含 H.264 视频流与 AAC 音频流
- [ ] `[分辨率]` 严格符合 1920×1080 (16:9) 或 1080×1920 (9:16)，像素格式为 `yuv420p`
- [ ] `[音画同步]` 视频与音频总时长偏差 ≤ 0.35s（无截断或尾部画面死等）
- [ ] `[响度削顶]` 平均响度在 [-35dB, -12dB] 广播级标准内，峰值无削顶失真（< 0dB）
- [ ] `[死黑屏]` 全片无持续 > 1.5s 的死黑帧异常
- [ ] `[字幕时间线]` 字幕时序单调递增、无时间倒挂、无负时长、收尾与全片对齐
- [ ] `[帧率码率]` 帧率稳定 24–60 fps，码率健康（> 200 kbps）

## 三、导出物（回读，不能只看导出命令）

```bash
python3 scripts/svg_to_pptx.py projects/xxx -o output/xxx.pptx
unzip -q output/xxx.pptx -d /tmp/chk
```

- [ ] 门禁 blocking = 0
- [ ] `ppt/media/` 文件数 = 预期图片数
- [ ] 每页 `<p:pic>` 数量 = 预期（内容页应为 1）
- [ ] `grep sz=` 换算回 px（**1pt = 0.75px** @1280×720，42pt = 56px）
- [ ] **同一角色的 pt 值在各页一致**

**这一节不能省。** 源文件对了不代表导出对了。字号最终是从 PPTX 里反查 `sz=` 才确认一致的。
