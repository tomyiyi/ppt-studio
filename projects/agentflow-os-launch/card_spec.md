# card_spec —— 卡片版式契约

卡片的唯一真源。改卡片字号只改这里，`qa_cards.py` 从这里读阶梯。

## canvas

```
1080 × 1350   (3:4)   微信 / 小红书主力
1080 × 1920   (9:16)  视频号 / 抖音封面
1080 × 1080   (1:1)   朋友圈方图
边距 80 · 硬安全边 64 · 图片带 700 · 页脚基线 1300
```

## typography

卡片不是把横版字号等比缩放 —— 手机上会小到读不清。
竖版有自己的阶梯，比横版相对大得多：

```
28  eyebrow / 页脚      ← 源 11 / 13
36  body    正文        ← 源 16 / 20
44  subtitle 副句       ← 源 24
56  title   英文副标    ← 源 32
72  statement 主句      ← 源 56
96  metric  指标数字    ← 源 44
132 hero    封面主标    ← 源 96
```

## layout

```
0–BAND    图片带：底图 slice + 竖向 scrim + 底部 130px 渐隐进面板
          眉标 y=112 · 徽章右上角 y=80（数字进圆牌，标签排在下面）
BAND–1350 内容面板：主句（左侧 6px 强调竖线）+ 副句 + 指标数字
1250      页脚基线：左「来源」右「页码」
```

主句左侧的 6px 强调竖线是卡片的签名元素，所有卡片保持一致。

### 图片带高度自适应（40%–62%）

不是固定比例。固定 47% 时，只有一句主句的卡片下半屏空着
（实测 04 面板墨量仅 2.96%）。现在按内容量反向推导：

```
band = clamp( H − (72 + 内容栈高 + 页脚区),  H×0.40,  H×0.62 )
```

实测：01 = 47.7% / 02 = 40.0% / 03 = 49.7% / 04·05·06 = 60.8% / 07 = 53.7%。

### scrim 不能压太狠

第一版 `0.88 / 0.42 / 0.08 / 0.30` 把 P99≈60 的暗图压到整带墨量 0.7%，
等于没有图。现用 `0.78 / 0.28 / 0.05 / 0.16`，只护住顶部眉标那一条。

## 装配优先级

装不下时按序丢弃，卡片只装得下一个主张：

```
主句（永不砍） > 副标 > 指标数字 > 副句① > 副句②
```

02 页因此保留了三个数字、丢了场景描写 —— 数字比正文更适合卡片。

## focus

源画布里没有 statement 档（源 44–71px 非数字文本）的页，
用 `页码: 主句` 人工指定卡片主句 —— 机器猜不出哪一栏才是这一页的论点。
