## PPT 设计/写作层调研（只读，未改任何文件）

| 方案 | 写作层 | 版式/封面层 | 一句话理由（对比 ppt-master Strategist+styles） |
|---|---|---|---|
| codebuddy ppt-writer | 持平偏弱 | 弱 | SCQA/金字塔是通用框架，无逐页断言校验、无版式资产 |
| trae ppt-generator | 略强 | 持平 | "narrative thesis→每页一个 narrative job→证据计划"最成体系，但仅 21 style/25 layout 且只出 HTML 不出 PPTX |
| jingmei-ppt | 弱 | 持平偏强 | 视觉总监式 style brief+6 场景配方+PptxGenJS 落地，无写作校验 |
| anthropics pptx | 无 | 持平 | 强在 OOXML 工程红线与 QA 脚本，设计仅经验清单 |
| brand-guidelines | 无 | 弱 | 单一品牌 token，非通用设计层 |
| ppt-keynote / article-magazine | 无 | 弱 | 十行小配方，无资产库 |
| guizang-ppt-skill | 持平 | 强（局部） | 瑞士风 22 锁定页型+字号字重阶梯+validator，封面/版式工艺最强，但仅 HTML、叙事只有"叙事弧" |
| html-ppt-skill | 无 | 持平 | 36 主题/31 版式量大但浅，无写作层 |

**结论（3 行）**
1. 本机没有任何 skill 在两层同时明显强于 ppt-master；值得"吸收"不值得"替换"：借 trae 的证据规划强化 Strategist 写作层，借 guizang 的版式锁/校验器强化封面与中文排版。
2. GitHub 侧：presenton（约 11k star，README 已实际打开读，线索级以上）是 Gamma 式模板工具，无断言式写作层；reveal.js（约 72k）/marp 是通用 slides-as-code 引擎非 AI 设计层；ppt-master 实测约 58k star，为同类最大。
3. 证据分级：另见"26 个 PPT Skill 梳理"等仅搜索摘要（线索级），未逐篇核验；未发现口碑明显更高且可直接替换设计层的公开方案。
