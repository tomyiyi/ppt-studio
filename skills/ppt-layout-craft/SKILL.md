# 版式与排版规则（内容页）

> 定位：只管**怎么排**。写什么见 `ppt-narrative-writing`，封面见 `ppt-cover-design`。
> 画布 1280×720（导出按 `width=1920 height=1080 viewBox="0 0 1280 720"`）。
> "更高级、美观"是主观表述，**不可判定**；本 skill 把它翻译成 §2 的四指标代理量。
> 证据级：**A**=一手原文 / **B**=页面要点或二手全文 / **C**=摘要或推断 / **D**=本仓自定 / **M**=本轮实测第一方。

## 1. 栅格与版心

| 编号 | 规则 | 级 |
|---|---|---|
| L-01 | **版心 = 画布宽 6%**（1280 → 边距 76.8，实现取 `M=76`）。四边不得有文字/线条越过 | A/B |
| L-02 | **12 栏栅格**：`X0=76`、`COL=72`、`GUT=24`，自检 `76 + 12×72 + 11×24 + 76 == 1280`。正文块跨 5-6 栏，主视觉跨 7-8 栏（画布 60-65%）；正文左齐、右侧不齐 | B/M |
| L-03 | 间距只允许 4 的倍数阶梯 `4/8/12/16/24/32/48/64`；同级块间隙 = 块内 padding 的 2 倍 | B |
| L-04 | 基线步进 8px；顶部标题区 ≥64px、底部来源带 ≥48px（下边距 > 上边距） | B/D |
| L-06 | 单页离散元素 ≤7；同级块 ≤6/屏；要点 ≤5 条、每条 ≤2 行；表格 ≤5 列（>5 列拆页）、>10 行分页 | B/D |
| L-07 | 分组优先用**留白**（组间 ≥32px）+ 一条 1px 分隔 + 16px 灰组标题。只有需要"层/域"语义才画容器（1px 描边或 4% 底色），最多两层，**禁卡套卡** | D |

**已知不一致（M）**：`qa_layout.py` 里 `MARGIN = 60`（4.7%），比 L-01 的 6% 松。以 **76 为准**（更严），不要为了过 QA 把版心缩到 60。

## 2. 尺度与层级（"高级感"的可测代理）

| 编号 | 规则 | 级 |
|---|---|---|
| L-09 | **一屏有且仅有一个 L1**（44 或 32 的断言标题）；L2 小标题 20/24；L3 正文 16/13 | B |
| L-10 | 四指标：字号比 ≥2.5、留白率 35-50%、离散元素 ≤7、坐标全落 8px 网格 | D（推导，非一手规范） |
| L-08 | 层级差 ≥1.5×，同档字号不用于区分层级 | B |
| L-14 | 字号下限：**禁 <11px**；注释/来源 ≥13px；正文 ≥20px，投幕建议 ≥24px | A（TTU 正文最小 18pt） |
| L-15 | **强调预算 ≤2 处/屏**（1 主 + 1 副），每处只用一种手段（字号/字重/颜色三选一），禁"加大+加粗+变色"叠加；单页配色 ≤5 种 | A |
| L-16 | 对比度：正文 ≥4.5:1；≥24px 大字可降到 3:1；分隔线/图标 ≥3:1 于背景；AAA 参考 7:1 | A |

**档位系统（裁决 X-C1）**：沿用 `spec_lock.md` 九档 `11/13/16/20/24/32/44/56/96`，**外加提案档 `poster: 160`**。
外部有"九档差仅 1.25 导致填字感，应改 1.618/2.5 大跨比"的说法（R5，自承为推导）。本仓裁决：**保留档位契约 + 加一条用法约束**——

> **L-08b（M）**：同一屏内相邻层级必须**跨 ≥2 档**（如 44 → 20 → 16 合规；44 → 32 → 24 违规，是"填字感"的真正来源）。
> 用 `poster:160` 前必须先把它写进 `spec_lock.md`，否则违反自家档位门禁（X-06）。

**留白率的诚实口径（M）**：按"文本/图形包围盒面积"估的留白率会**系统性低估**（实测数据表页 14.8%、机制页 24.3%，肉眼并不觉得挤，因为包围盒内含大量空行距）。所以 L-10 的 ≥40% 只能对"墨量像素占比"成立，**包围盒估法不得当门禁**，只作趋势参考。

## 3. 线宽与图形

| 编号 | 规则 | 级 |
|---|---|---|
| L-17 | **线宽三级**：1px 辅助/虚线（dash `4 3`）／1.5px 普通连接／3px 主链。主链须 ≥2× 普通线 | A |
| L-18 | 同页箭头只一种尺寸（三角 8×5px）；折线走 90°，圆角 r=4~6px | A |
| L-19 | 分区用 hairline 0.75-1pt 细线，不用粗框 | B |
| L-20 | 机制/流程页：主链单向（左→右或上→下）、节点 ≤6；同层节点等宽，单节点宽 ≤320px、高 ≥88px；卡片圆角 8px、描边 1px、内 padding 20px；连接线只走水平/垂直；**回流/反馈线走外侧且用虚线** | A/D |
| L-21 | 编号徽标统一 **24px 圆内 13px 数字**；分支标签 13px 贴线上方 4px；图例仅当线型 >2 种时出现（右下，13px）；节点标题 16~20px、说明 ≤3 行 13~16px；关键结论区 = **24px 断言句 + 3px 主链色条** | A/D |
| L-22 | 面板面积 ≥6% 画布，内 padding ≥ 字号×1.2，面板间隙 ≥32px | M（沿用既有门禁） |

**实测补充（M）**：卡片高度应**随节点数收缩**（`nh = 34 + n×32 + 12`）。三组卡片等高时，只有 1 个节点的"交付"组会留一个 100px 空洞，观感明显变差；收缩后主链连线走第一行高度（`cy = ny+56`），反馈线走最高组底边下方 40px。

## 4. 表格（三线表）

| 编号 | 规则 | 级 |
|---|---|---|
| L-23 | **去家具**：0 竖线、0 外框、默认 0 隔行底纹。顶线/底线 2px（1.5pt），栏目线 1px（0.75pt），行间线 ≤0.5px 或直接留白 | A |
| L-24 | 数字**右对齐并按小数点对齐**，文字左对齐；数字须 tabular figures（拿不到 `tnum` 就改等宽字体 Menlo）；数字列之间不用竖线而用 ≥24px 空隙 | A |
| L-25 | **单位下沉**：单位写进表头（"营收（亿元）"）或紧跟数字用 13px 灰字，与主数字差 ≥1 档；KPI = 主数字 44~56px + 单位 13px + 释义 16px，单位与数字同基线 | D |
| L-26 | 高亮单元格 ≤2 个且 ≤总格数 20%，**只用底色**（主色 8%-12% 不透明度）或一档字重；禁描边、禁红黄绿三色并列；强调一列用"该列加粗 + 顶栏 2px 色条"，不叠底色 | B |
| L-27 | 表头下 1.5~2px 主线；首列起点 = 版心左边距（不做居中表头）；表头 16px 不放大不居中；行高两档：≤5 行 48px、6~10 行 40px；表格撑满版心；表上方与标题留 ≥32px | B/D |
| L-28 | 来源行 13px 灰字，贴版心下边距上方 8px，格式固定「数据来源：…；统计口径：…；截至 2026-10」 | B/C |
| L-29 | 空值写"—"居中、0 写 0；负值同色系不加红（除非语义必须）；高亮格用 13px 注号 ① 指向 | D |
| L-30 | 数据页用 **direct labeling** 替代图例 | B |

**实测参考值（M，`10_table_v2` 已过全部门禁）**：`表顶 ty=252`、`表头高 hh=32`、`行高 rh=40`；表头三项分别 `左起 X0+4 / colx(2)+4 / 右对齐 W-M-4`；行间浅线用 `STRUCT + opacity 0.18`（不是斑马纹）；强调行用 `CAUTION fill-opacity 0.10`。

**斑马纹裁决（X-C4）**：默认 0；>8 行才允许 ≤5% 明度差条纹。有冲突说法主张"完全禁用"，本仓取**更严的默认 0 + 显式例外**，且例外必须写明行数条件。

## 5. 中文排版特有

| 编号 | 规则 | 级 |
|---|---|---|
| L-31 | 中西文之间、中文与数字之间插 **1/4 全角空格**（≤1/4 字宽）；SVG 里用 U+2005 或 `tspan dx`，不要用半角 U+0020 | A |
| L-32 | 全角标点两侧不加空格；数字与 %、数字与单位不加空格（12%、5 亿） | B |
| L-33 | 测宽必须把行尾标点计入（clreq 允许二分标点压缩，SVG 无 `text-spacing`，按整宽计费会低估溢出） | A |
| L-34 | **避头尾**：行首禁 `，。、；：？！」』"`，行尾禁 `（《「'`；不得依赖自动换行，必须手工断行并把标点随字带走 | A |
| L-35 | 破折号/省略号占 2 字宽且不可拆行；省略号占 2 汉字宽居中、间隔号占 1/2 汉字宽 | A |
| L-36 | **投幕一律黑体**（屏显/强调用黑体，宋体只用于印刷正文）。宋体细笔画在投影/低 DPI 会糊；11px 及以下黑体笔画粘连，该档只用于来源行或改 13px | B |
| L-37 | 中文正文行高 = 字号 ×1.6~1.75（投幕取 1.6）；标题 ×1.2~1.3 | A |
| L-38 | 标题居中换行不得断在词中（中文无空格分词须手排）；不用全角空格做缩进，改用 x 坐标 | D |
| L-13 | 中文一行 **≤28 字**（裁决 X-C3：外部给 18-28 与 29-35 两种，投幕取更严的 28），>28 必须断栏；双栏间距 ≥ 栏宽 1/3 | A/D |
| L-11 | 行高不足 1.6 时中文上下标点互挤；WCAG 底线 1.5，中文建议 1.5-1.8 | A/B |

**测宽函数（M，可直接复用）**：`cjk(s) = Σ(1.0 if ord(ch)>0x2E80 else 0.55)`；`qa_layout` 用的是 `CJK 1.0 / 拉丁 0.52 / 等宽 0.60`。**两套系数不同**，自检请按 QA 的口径取更大者（0.60）才不会漏判溢出。

## 6. 对比度：怎么测才算数（本轮最重要的工程结论）

1. ~~**不能只信 `qa_layout.check_contrast`**~~ → **2026-10-08 已修（见 B-5）**。旧版取区域 20 分位=背景、99.5 分位=笔画，对**细笔画大字号中文**会误判：实测 «不等于设计»（96px 宋体）报 1.4:1，像素统计证明区域 `min=6, p20=242, p99.5=250` —— 它把浅色背景当成了笔画。现版用 Otsu 二分类，合成真值 15.9:1 测得 15.8:1，**大字已可自动判定**。
2. **最坏情况合成自检法（M，可脚本化）——仍然要保留，它是"渲染前"的判据**：把底图保守取**纯白**，逐层合成压平色与遮罩色，取**文字块右端（遮罩最薄处）**算对比。实现见 `gen_covers.py` 的 `v3_bg() / comp() / ramp() / check()`。本轮靠它抓出 4 处真实不达标（11px kicker 3.5-4.3:1、V3 页脚 3.99:1）。它和第 1 条不重复：一个在生成时防错，一个在交付后复核。
3. **修法优先级**：先升字号档（11→13），再加深色值（`MUTED #4A4536`、新增 `SUB2 #C6D8E8`），最后才加遮罩。实测 11 档"可判定但不可用"（X-05），新页一律从 13 起。
4. **压平/遮罩可用台阶（M）**：单色压平 `FLAT_A=0.34`；方向性渐隐遮罩 `0→0.86 / 0.42→0.58 / 0.68→0.16 / 1→0.00`。**遮罩必须方向性，禁整幅糊**。

## 7. qa_layout / vendor 门禁盲区（M）—— B-1/B-2/B-5 已于 2026-10-08 修脚本

| 编号 | 现象 | 现状 / 绕行写法 |
|---|---|---|
| B-1 ✅已修 | **压行误判**：`check_line_collisions` 旧版用**原始 x 属性差 ≤24** 判同列，不解析 `text-anchor`；且把**同基线的行内并排**（项目符号 + 正文、数字 + 单位）也当压行 | 现判据 = **渲染盒水平 + 垂直双向重叠**；同基线对要求横向重叠 ≥8px（测宽是启发式，留误差），跨行 ≥4px。回归：workflow_full 18 页 **25 条误报 → 0**，且**没有任何一页变差** |
| B-2 ✅已修 | **面板检测失明**：`panels_of` 旧版只识别 `clipPath` 里的 `<rect>`，而 vendor 门禁要求局部裁切必须用 `<path>` → 合规写法反被报"无独立图片面板" | 现支持 `<path>` / `<polygon>`（绝对直角路径精确，含曲线时取**偏大**的保守盒），并与 `<image>` 自身矩形**求交**收敛。实测 V2 封面 hero 面板被认出：`panel:v2-panel 590x720 墨量 13.54% 对比 3.6:1` |
| B-5 ✅已修 | **大字对比度不可判定**：`check_contrast` 旧版写死"背景=20 分位 / 笔画=99.5 分位"，隐含墨量占比 ≈20%；96px 细笔画中文墨量只有几个百分点，两个分位同时落在背景上 → «不等于设计» 误判 **1.4:1** | 现用 **Otsu 二分类**定背景/笔画，笔画取少数类的"核心端"（最暗/最亮 25%），抗锯齿边缘不计入。合成用例真值 15.9:1 → 测得 15.8:1；真低对比 1.47:1 仍能抓出；暗底亮字方向正确。**不再需要"大字交人工"这条豁免** |
| B-3 | **clipPath 写法**：`<rect>` 做局部/偏移裁切 = blocking；`clip-path` 挂外层 `<g>` 也 = blocking | `<clipPath><path d="M690 0 H1280 V720 H690 Z"/></clipPath>` + `clip-path` 挂在 `<image>` 上 |
| B-4 | **导出前置**：`svg_to_pptx.py` 拒绝没有通过 final 报告的工程（not-provided） | 必须**在项目目录内**先跑 `svg_quality_checker.py --stage final`，再导出 |

**回归与自检的可复现入口（M）**：`scripts/test_qa_layout_fixes.py`（15 条合成用例，不依赖真机渲染）
与 `spikes/2026-10-08-design-layer-v2/qa-regression/regression_qa.sh`（改前版本从 `git show HEAD:` 取，
同一批 23 张渲染图跑两版对账；`old.txt` / `new.txt` / `diff.txt` 已留档）。

**剩余真实待修（不是 QA 误判，别当噪声）**：workflow_full 改后仍 `待修 30 项` = 21 条 «•» 对比度不达标
+ 9 条字号越出阶梯（22 / 72 不在 ramp）。红色项目符号 #B4232A 压在近黑底（实测背景 RGB≈2,1,1）上
**真实对比只有 3.20:1**（独立采样验证，与 QA 报的 3.4:1 同量级）→ 属设计问题，留给 spec 裁决：
要么改符号色/底色，要么明确"装饰性符号不按正文 WCAG 判"。

**截图判据（M）**：SVG 根 `width=1920 height=1080 viewBox="0 0 1280 720"` → Chrome 必须 `--window-size=1920,1080 --force-device-scale-factor=1`，否则只截到左上 853×480 被误判"内容被裁"；`qa_layout` 需要 1280×720 渲染图（`sips -Z 1280`）。
**样式规范（M）**：根 `<svg>` 给唯一 `font-family` 默认值，子文字节点只写真实覆盖，否则产生 `noncanonical-authoring` WARN。每页根节点必须带 `<title>`（实测 18 条 WARN → 0）。

## 8. 参考实现

`spikes/design-v2/gen_pages_v2.py`（内容页 v2）与 `gen_covers.py`（封面 v2）。两页均通过：
vendor 门禁 `exit=0 / errors 0`、`plan_contract 页面 2 错误 0 PASS`、`qa_layout ALL CLEAR ✅`（对比最低 8.3:1 / 9.1:1，不达标 0/33）。
导出 `D.pptx 18,376B / 2 slides`。

**字体栈（2026-10-08 定稿）**：黑体首站一律 `Noto Sans SC`（SIL OFL 1.1，黑苹果已装 Real），完整栈
`Noto Sans SC, PingFang SC, Microsoft YaHei, sans-serif`；等宽 `Menlo, monospace`；衬线只在需要印刷感时用 `Songti SC, STSong, serif`。
理由：`STHeiti Light` 不在 vendor `PPT_SAFE_FONTS` 也不在 `FONT_FALLBACK_WIN`（表里只有不带后缀的 `STHeiti`），是唯一那条
`unsafe_exported_font_faces` 的来源；换栈后 `/checks/font_portability = passed`、封面 + 内容页 warning **双双归零**。

**导出 face 会被改写（M 实测，做设计判断时必须记住）**：`FONT_FALLBACK_WIN` 把 `Noto Sans SC` / `PingFang SC` /
`Hiragino Sans GB` / `Source Han Sans SC` 统一映射成 `Microsoft YaHei`，`Songti SC` → `SimSun`。
所以 **macOS 截图不代表 Windows 放映效果**；本项目 `spec_lock.md` 第 34 行锁的正是 `Microsoft YaHei, Arial`。
真·嵌入 OFL 字体当前**不可达**：`svg_to_pptx.py` 无 `--embed`，`pptx_embedded_fonts.py` 只能从**源 pptx** 携带 `embeddedFontLst`。

**未闭环（不得称已验收）**：
1. 宋体标题在投影仪上的糊笔画未实测（与告警无关，是独立可读性风险）。
2. spike SVG 带 `quality_introduced_warnings`：封面 6 条 / 内容页 4 条，全是**作者契约**缺项 ——
   `ungrouped top-level Slide-local element(s)`（未把逻辑单元包进 `<g id="…">`）与
   `page SVG is missing root data-pptx-page-role`（未声明页面角色）。非 blocking，但生产管线必须补齐这两项，
   否则每次交付都带 warning。
