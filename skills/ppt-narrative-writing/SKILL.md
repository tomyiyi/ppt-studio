# PPT 写作规则（内容层）

> 定位：本 skill 只管**写什么**，不管**怎么排**。排版见 `ppt-layout-craft`，封面见 `ppt-cover-design`。
> 输入是 `pages.json` 之前的文稿，输出是每页一个可被反驳的断言 + 支撑它的证据。
> 规则编号 W-xx；证据级：**A**=读过一手原文 / **B**=页面要点或二手全文 / **C**=仅摘要或推断 / **D**=本仓工程自定约定。

## 0. 验收边界（先读这条）

实测事实：三套封面样张 vendor 门禁同为 `errors 0`，用户判定仍是"封面没有视觉主角"。
**门禁通过只是必要条件。** 写作层的验收只能靠下面的可判定测试 + 一次人读。
禁止把"脚本没报错"写成"内容合格"。

## 1. 五条硬红线（命中即退回重写）

| 编号 | 规则 | 判定方法 | 级 |
|---|---|---|---|
| W-01 | 每页标题是**含动词的完整判断句**，只含一个断言。"××背景/概况/分析/总结"类名词短语标题一律退回 | 标题里必须能找出一个谓语动词；`grep -E '(背景|概况|分析|介绍|说明|总结|举措)$'` 命中即违规 | B |
| W-02 | 标题长度 **中文 ≤24 字、≤2 行、每行 ≤16 字**（裁决见 §6-A6：外部有 ≤18/≤25/12~24 三种口径，本仓取 24，与 `assert len(title) <= 24` 一致） | 脚本断言，实测 `gen_pages_v2.py` 两页均带此断言 | B/D |
| W-03 | **可反驳测试**：标题必须能被一句"我不同意"回应。不可反驳的（"XX 的现状"）改写为数字句 / 比较句 / 因果句 | 人工：能否写出反命题 | B |
| W-06 | **一页一论点**：论点数 = 页数，1:1。标题可拆成两句即判拆页 | 标题里出现"和/及/以及"连接两个结论 → 拆页 | B |
| W-24 | **禁空词**：进行、实现、打造、赋能、抓手、闭环、沉淀、值得注意的是、无对象的"大幅提升/明显优化"、三段式排比空洞句。每页合计命中 >1 次即违规 | 词表 grep；来源 deslop-zh `SKILL.md`（A 一手仓库文件） | A |

## 2. 论证结构

| 编号 | 规则 | 级 |
|---|---|---|
| W-04 | **标题链测试**：按顺序只读全部标题，能复述完整论证链。读不出链条 → 补 governing thought 或改标题 | B |
| W-05 | 写页面前先产出**全场一句话论点**（governing thought）并单独存档；每页标题必须是它的 MECE 子断言 | B |
| W-10 | **Answer-first**：每章第一页是结论页。SCQA 只用于开场 3 页（S=1 页共识事实、C=1 页冲突、A=主体，Q 不单独成页） | B |
| W-17 | 每个论证段至少一次**显式对比**（现状 vs 目标 / 我方 vs 对手 / 前 vs 后），≥1 组 | B |
| W-09 | 每页必须有 **so-what 落地句**（含义或行动），页尾 1 句 kicker。写不出 so-what 的页移进附录 | B |
| W-28 | 结尾行动清单每条 = **动词 + 对象 + 时限/责任人**，≤3 条 | C |

## 3. 证据与数字

| 编号 | 规则 | 级 |
|---|---|---|
| W-07 | 每页正文只有**一个证据对象**（图/表/对照/截图），文字注释 ≤3 条。bullet >5 条或单条 >15 字 → 拆页 | B |
| W-08 | 禁 bullet 墙：≤3 块、每块 ≤2 句、每句 ≤24 字 | B |
| W-12 | 数字必须带**比较基准**（同比/环比/对标/目标）。裸数字违规，每页显式基准 ≥1 | C |
| W-13 | 程度词一律替换为「数值 + 单位 + 对比基准 + 数据来源」。给不出数字就弱化措辞，不许用形容词撑结论 | B |
| W-15 | 全部数据须标来源；引用页含**出处 + 时间 + 样本**。来源行格式见 `ppt-layout-craft` L-28 | B |
| W-22 | 图表关键数据点必须有**紧邻文字标注**；每页图表必须有来源行 | B |
| W-27 | 页面每个数字能**回指素材原文位置**；回指不到的删除 | B |
| W-29 | 对素材的**逐句照抄率 ≤40%**，超出判"未提炼"（D：本仓工程自定，无外部来源） | D |

## 4. 认知与受众（只作设计理由，不作门禁）

| 编号 | 规则 | 级 |
|---|---|---|
| W-20 | **30 秒 glance test**：只读标题 + 看图能复述本页论点；不了解上下文的人 5 秒内能说出断言 | B |
| W-21 | Coherence：与本页断言无关的元素（装饰图、logo 墙、顺带数据）删除 | B |
| W-23 | Redundancy：页面上不放讲稿全文；除标题与图注外正文 ≤60 字 | B |
| W-26 | 受众分层：决策者版前 3 页必须含结论、成本、风险；实现级技术细节只进附录 | B |
| W-19 | 教学页固定结构：概念定义（≤30 字）→ 正例/反例各 1 → 当堂检查题；每概念 ≥1 例 | C |
| W-18 | 机制页必须 ≥3 节点的因果/流程图，禁止纯文字讲原理（画法见 `ppt-layout-craft` L-20） | B |

**禁止引用的说法**（X-10/X-11）：不得写"Assertion-Evidence 教学法提升学习效果 X%"——psu 官网抓取失败、2009 论文仅核实 DOI，效应量数字未获一手确认。"图片优势效应""越抽象越记不住"无阈值，只能当设计理由，不能当验收判据。

## 5. 五类页面内容骨架（直接当 `pages.json` 字段）

| 页型 | 必填字段 |
|---|---|
| 封面 | `title_claim(≤12)` / `subtitle_takeaway(≤24)` / `audience_question` / `presenter+date` |
| 结论页 | `assertion` / `evidence_points(≤3×≤24)` / `data_anchor` / `scope_note` |
| 数据页 | `action_title` / `chart_intent` / `highlight_series` / `baseline` / `annotation(≤15)` / `so_what` |
| 机制页 | `assertion` / `diagram_nodes(≥3 + 因果标签)` / `concrete_example` / `counter_case` / `implication` |
| 教学页 | `concept_def(≤30)` / `analogy` / `good_bad_pair` / `check_question` / `summary_card(≤2 行)` |

数据页标题写法（W-14）：直给图表要点、动词优先，像新闻 headline，不像图表标签；问句式标题仅限悬念页。

## 6. 冲突裁决（外部规则互斥，本仓只认一条）

| 编号 | 冲突 | 裁决 | 理由 |
|---|---|---|---|
| A6-1 | 标题字数 ≤18 / ≤25 / 12~24 | **≤24 硬，≤18 首选** | 与实测 `assert len(title)<=24` 一致；18 作为软目标写进自检提示 |
| A6-2 | 正文长度 ≤40 字（表格页）vs ≤60 字（W-23） | 表格页 **≤40**，其余 **≤60** | 表格页文字是注释不是正文 |
| A6-3 | bullet 上限 5 条 vs 6 行×6 词 | **≤5 条，每条 ≤2 行** | 与 L-06 离散元素 ≤7 对齐，取更严者 |
| A6-4 | 照抄率 ≤40% 无外部来源 | 保留，标 **D 级约定** | 可判定、可脚本化，但不得称"规范" |

## 7. 自检清单（交付前逐条打勾）

1. 只读全部标题，能复述论证链？（W-04）
2. 每个标题能被"我不同意"回应？（W-03）
3. 有标题找不到动词，或是名词短语？（W-01）
4. 有页面 >5 条 bullet，或单条 >15 字？（W-07）
5. 每个数字都有基准 + 来源 + 时间？（W-12/W-15）
6. 空词表 grep 命中 ≤1？（W-24）
7. 每页有 so-what？没有的页是否已移附录？（W-09）
8. 结尾行动清单 ≤3 条且带时限/责任人？（W-28）
