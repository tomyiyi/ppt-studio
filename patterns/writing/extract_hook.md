# extract_hook

为整篇内容提炼封面钩子（让人想翻页的那句）。

## 输入
- `title`: 文章标题
- `claims`: 各节 claim 列表

## 输出（JSON）
```json
{
  "hook": "封面主标题（12字以内，观点断言）",
  "subhook": "封面副标题（20字以内，补充信息）"
}
```

## 规则
1. hook 是断言，不是描述。坏："5条硬核准则分享"，好："AI 的自信是设计出来的"
2. 用数字制造具体感（"5条"比"几条"好）
3. 制造认知冲突（"你以为的 X，其实是 Y"结构）
4. subhook 回答"这跟我有什么关系"
