# rewrite_slide_copy

把提取的主张改写成演示型文案（适合放在 PPT 页面上）。

## 输入
- `claim`: 核心主张
- `evidence`: 论据列表
- `layout`: 目标版式（bullets/statement/compare/steps）

## 输出（JSON）
```json
{
  "slide_title": "页面标题（观点句，12字以内）",
  "bullets": ["短句1（20字以内）", "短句2", "短句3"],
  "takeaway": "本页记忆点（一句话，15字以内）"
}
```

## 规则
1. slide_title 是观点，不是章节名。坏："准则一"，好："AI 的自信是必然"
2. bullets 每条是一句完整的话，去掉修饰，保留动词和数字
3. 数字、对比、反差优先保留（"73% vs 46%" 比 "效果更好" 好）
4. takeaway 是观众合上电脑后还能记住的那句
5. 绝对不要超过 4 条bullets

## 实现边界（重要）

**这套规则目前没有规则版实现，也不应该有。**

`scripts/narrative_rewrite.py` 曾经尝试用正则实现本pattern
（`claim[:12]` 硬截断等），结果是**产出正是本文件规则 1 明令禁止的坏输出**：

```
原文  : 确定性：不是更准，而是可被追溯
  标题: 确定性← 砍成半句，观点全丢
```

**为什么正则做不到**：把「陈述句」变成「观点句」需要理解语义与语境，
这是创作判断，不是字符串操作。任何 `[:N]` 形式的截断都必然切断语义。

### 当前实现策略：**只筛不改**

`md_to_pages.py` 的 `title_quality()` / `resolve_title()` 采取保守策略：

| 情况 | 处理 |
|---|---|
| 标题有主副结构且主句可独立成立 | 取主句（如 `网络安全：零信任不是口号` → `网络安全`） |
| 标题本身就是完整观点句 | **原样保留，不截断** |
| 只有章节编号（`准则一`） | 标记 `needs_review`，交人/LLM |
| 过短（疑似被截断的半句） | 标记 `needs_review` |
| 超长且无法断句 | 标记 `needs_review` |

不合格的标题**不截断、不编造**，原样带标记输出，并在终端打印待审清单。
规则层在这里的价值是**挑出坏标题**，不是替人写好标题。
